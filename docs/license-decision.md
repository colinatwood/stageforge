The consolidated repository contains an Apache-2.0 LICENSE from GitHub main.
The recovered archive did not contain that file. Release approval still requires
the owner to confirm the recovered source and final distribution are covered and
to review the dependency inventory. Publication must remain blocked until the owner
selects a license compatible with the intended open-source/commercial model and the
final distribution dependency inventory. The code must not be described as open
source merely because source is available. After selection, add the exact license
text, copyright holder/year, source headers if required, contribution terms, and
release-package notices. This is an owner/legal decision reserved for final review.
